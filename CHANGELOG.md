# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html),
and is generated by [Changie](https://github.com/miniscruff/changie).


## v9.1.0 - 22-08-2026
### Added
* Voeg sortering op titel, ADR-score en API-versie in oplopende en aflopende volgorde toe aan GET /apis.
### Fixed
* Maak applicatielogging eenduidig voor Loki en Grafana en voeg aan elke logregel het app-veld toe.

## v9.0.0 - 17-07-2026
### Changed
* Update Go tooling to 1.26.5 and enforce 80% test coverage in CI.
### Fixed
* Sta registratie van een API via oasBody toe zonder verplichte oasUrl.

## v8.0.0 - 02-07-2026
### Changed
* Return API summaries in list and detail responses, derive summaries from descriptions up to 180 characters without cutting words, update Go dependencies including the quic-go fix for GHSA-vvgj-x9jq-8cj9, rely on the tools API to reject circular OAS dereference results, and update workflow action pins.

## v7.0.0 - 24-06-2026
### Changed
* Move shared register infrastructure helpers to don-register-common.

## v6.1.0 - 28-05-2026
### Added
* Added an RSS feed for the API. Updates when adrscore, lifecycle, hash changed or oas unavailable.

## v6.0.0 - 20-05-2026
### Changed
* Sort API filter options alphabetically instead of by result count

## v5.0.0 - 20-05-2026
### Changed
* Added DB-backed q search support to API list and filter endpoints while keeping the deprecated API _search endpoint available

## v4.1.0 - 01-05-2026
### Added

## v4.0.0 - 28-04-2026
### Changed

## v3.0.0 - 22-04-2026
### Changed
* Maak sunset- en deprecated-datums via PUT handmatig wijzigbaar zonder bereikbare OAS en werk de OpenAPI-documentatie hiervoor bij.

## v2.0.0 - 07-04-2026
